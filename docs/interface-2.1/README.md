# Interface 2.1 (protótipos)

Telas aprovadas do Casillas 2.1, em HTML estático, uma por arquivo. Servem de referência visual e de comportamento. Não fazem parte do app publicado: esta pasta fica fora das pastas do gate de produção.

- `telas/`: telas aprovadas. `referencia-anterior/`: protótipos antigos usados como base.
- `docs/`: estado atual, checklist de telas, decisões e regras de trabalho (cópia do Project "Dev Casillas").
- Ícones e logo são provisórios. Cálculos das calculadoras são de demonstração, sem revisão técnica.
- Nada aqui chama o Supabase. Códigos de teste nas telas de acesso são fictícios.
