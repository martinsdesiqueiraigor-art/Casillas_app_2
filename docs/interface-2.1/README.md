# CAS-UI (modernização da interface)

Pasta da frente CAS-UI. Não é a release `v2.1.0`.

- `telas/`: protótipos HTML aprovados, um por arquivo. São a referência visual vigente e podem ser substituídos por versões futuras aprovadas. `referencia-anterior/`: protótipos antigos usados como base. Esta pasta não faz parte do app publicado (fica fora das pastas do gate de produção).
- `docs/`: documentação oficial da CAS-UI (estado, decisões, produto e navegação, checklist de telas). O índice e a tabela de fontes estão em `docs/00-INDICE.md`. Estas são as versões oficiais; o Claude Project é apenas apoio.
- Ícones e logo são provisórios. Os cálculos nos protótipos são de demonstração, sem revisão técnica.
- Nada aqui chama o Supabase. Códigos de teste nas telas de acesso são fictícios.
